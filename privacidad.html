Política de privacidad

Agente Empleo es una herramienta de uso exclusivamente personal. No tiene usuarios externos.

Qué datos usa

Con el permiso de solo lectura de Gmail (gmail.readonly), lee únicamente las alertas de empleo de plataformas como LinkedIn, Indeed, Glassdoor e InfoJobs. No envía, modifica ni borra correos.

Cómo los usa

Extrae los datos de las ofertas y los compara con el currículum de su propietario. Para ello, el texto de las ofertas y del currículum se envía a la API de OpenAI.

Dónde se guardan

Los datos se guardan en el equipo o servidor privado del propietario. No se venden, no se comparten con terceros y no se usan con fines publicitarios.

Eliminación

El propietario puede revocar el acceso en cualquier momento desde la configuración de su cuenta de Google y borrar los datos almacenados.
